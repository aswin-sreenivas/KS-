# K S Associates — Engineering Construction & Surveying

Corporate website for **KS Associates Engineering Construction and Survey** (*"Building Trust, Creating Landmarks"*), based in Feroke, Calicut, Kerala.

**Built & Maintained by Gopika MK**

---

## Overview

A fast, responsive, SEO-optimized corporate web application showcasing K S Associates' civil engineering, construction, land surveying, and 3D architectural visualization services and project portfolio.

### Key Features

- **Corporate Brand Identity**: Deep Olive Green (`#343A24`), Muted Gold (`#C6A65B`), Warm Ivory (`#F5F4EF`), and Dark Charcoal (`#292B27`) palette with official transparent logo assets.
- **Multi-Section Portfolio & Project Lightbox**: Interactive project archive featuring 3D architectural renders, site plans, and floor plans (BC Road Commercial Complex, Chungam Apartment, Idimuzhikkal Commercial Building, Royal Villa at Feroke).
- **Direct Client Enquiry Channels**: Consultation request form, click-to-call (`+91 92074 46666`), and direct WhatsApp integration (`+91 99473 33150`).
- **Local & Technical SEO**: Open Graph cards, Twitter metadata, `robots.txt`, `sitemap.xml`, and Schema.org LocalBusiness structured data.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Deployment**: Vercel (`vercel.json` configured for SPA routing)

## Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start development server (http://localhost:3000)
npm run dev

# 3. Type-check
npm run lint

# 4. Build for production
npm run build
```

---

## Deploying to Vercel

This project is pre-configured for zero-friction deployment on **Vercel** via `vercel.json`:

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Import the repository in the [Vercel Dashboard](https://vercel.com/new).
3. Vercel will automatically detect **Vite** using `vercel.json`:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**.

Alternatively, deploy directly from the terminal using the Vercel CLI:

```bash
npm i -g vercel
vercel --prod
```
